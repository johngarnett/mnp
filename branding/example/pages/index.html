Example Pinball League

This is the home page of the example branding that ships with the server. A league keeps its own branding (this page, the rules pages, icons, emails and menus) in a separate repository and points the server at a checkout of it with BRANDING_FOLDER. See docs/branding.md.

Announcements, schedules and anything else the league wants on its home page go here. The file is plain HTML rendered inside the site's page frame.
